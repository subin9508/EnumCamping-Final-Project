## 기획 의도
캠핑 수요가 증가함에 따라 1인 캠퍼 (솔캠족)을 위한 캠핑장 필요성 대두.
다양한 기능 (예약, 결제, 커뮤니티 등)을 갖춘 캠핑장 웹사이트를 기획.
